/the eye into the system's functioning/

🚧 work in progress

oculuslambda is written in Lisp (Guile Scheme), leverages SXML, SQLite3, some basic POSIX / UNIX utilities, and the mighty GNU Artanis web-framework.

Monitoring tool, observability, alerting, dashboarding and more, all configurable in Lisp (Guile Scheme).
